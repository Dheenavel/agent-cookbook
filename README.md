# agent-cookbook

Standalone AI agent demos organized by the tool stack that powers them. Each agent lives in its own folder with everything needed to run it. No shared dependencies, no monorepo setup required — pick the one you want, follow its README, run it.

## Agents

| Tool | Agent | What it does |
|---|---|---|
| [JEV](./jev/) | [Page Search](./jev/page-search/) | Semantic search on any webpage via Chrome extension |

## Contributing

Each agent should be self-contained: its own `README.md`, dependencies, and runnable entry point. The README should be written so someone can paste it into an AI assistant and get walked through setup.
